# Plan 5: S4, the Multi-Agent Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build S4, the multi-agent panel, in the reframe design's build order. Code holds the Deal Record and makes the go/no-go call with the engine. The Deal Lead proposes issues. Investigators read against intent briefs, and a Committer checks every quote. The Challenger objects, backed by a pairwise screen. Router 6 orders the reading, and a residual sweep covers what nobody opened. Then check each build step against S1b on calibration deals, with the user's OK.

**Architecture:**
- **One `claude -p` session per role turn.** The existing tool server gains `--role lead|investigator|challenger`. Each role ends its turn with one closing tool call (`propose`, `report` or `challenge`), which the server validates and writes to the trace. The orchestrator reads the result back from the trace, so no free text is parsed.
- **`acqlab/agents/committer.py`** checks findings: verbatim quotes, numbers found in those quotes, and code arithmetic for computed values.
- **`acqlab/agents/record.py`** is the Deal Record, priced by the engine. It gives:
  - the engine's decision at the committed beliefs
  - each issue's flip amount
  - the pairs of issues that flip the decision together
  - router 6's ranking
- **`acqlab/agents/panel.py`** runs the loop. Its build steps are `Config`s: `s4_1` to `s4_3`, and `s4` itself.
- **`pilot.py`** runs the build steps and S4 like any other system, and compares each with S1b on the same deals.

**Tech Stack:** Python 3.12, uv, pydantic 2, numpy 2, pytest. Claude Code CLI 2.1.280+ for the real runs (controller only).

**Spec:** `docs/superpowers/specs/2026-09-24-reframe-design.md` §5 (S4, built against the measured failures), with the roles from `docs/superpowers/specs/2026-09-22-acquisition-lab-design.md` §3. The frozen benchmark and hypotheses are in `docs/results/plan-4b-preregistration.md`.

## Decisions made in this plan (review these)

The spec leaves these open; each was taken during pre-verification.

1. **Each role turn is its own sandboxed `claude -p` session.** It closes with a schema-checked tool call, so there is no free-text parsing.
2. **The Modeler is folded into the Investigator's `report`.** The main spec lists it as a Core role. The reframe's build order doesn't mention it, and `report` already returns typed findings in $M. Those findings are checked by the Committer, which does the Modeler's job without an extra LLM turn.
3. **No stall counter.** The Deal Lead re-plans after *every* investigation, which covers the progress ledger's "N stalled rounds → re-plan" rule.
4. **The router's stop threshold (veto) is 0.** It stops only when no open issue has any decision value left. Unspent budget earns nothing under the regret score, and Track A's veto of 0.0025 × asking price per page stopped S4 before any reading on ordinary deals (Findings, item 3).
5. **A document is paid for once per S4 run.** Later sessions re-open it for free, which matches S1b keeping a document's text in its context. Budget spent is the sum of trace costs across all sessions, and it never exceeds the deal's budget.
6. **An Investigator's budget** is min(what's left for directed reading, max(pages of the first unread suggested document + 2, ⌈0.5 × deal budget⌉)).
7. **The engine decides at the committed beliefs.** Committed values are fixed. Open issues keep the Deal Lead's chance, over its range widened to at least the usual size (`typical_high`), as router v4 does. The call is go if the expected regret of going is no higher than passing, and the walk-away is the median.
8. **An objection buys one more investigation of that issue.** While it is pending, the issue is priced at the objection's chance and size where those are higher, so the router can rank the check and the Lead can't drop it. An objection nobody could afford to check changes nothing in the final call.
9. **S3's N counts all four token kinds:** input, output, cache read and cache write.
10. **Out of scope, for Plan 6:** the ablations (−Challenger, −residual sweep, "LLM decides", −engine). −Challenger and −sweep will each be one `Config` line. "LLM decides" and −engine need new code.

## Review Focus

These five input classes or failure modes aren't exercised by the spec's own tests. Each line names the test that pins it.

1. **A quote copied with different spacing, case, dashes or markdown table pipes** must still match its document. `test_a_quoted_amount_is_committed_and_quotes_match_despite_markdown_case_and_dashes` (Task 1).
2. **A report the Committer refuses** must not end the Investigator's turn, so it can fix the report and retry. `test_report_goes_through_the_committer_and_ends_the_turn_only_when_accepted` (Task 3).

## Findings from pre-verifying this plan (read before starting)

All the code below was run before this plan was written. It passes 264 tests; the suite takes about 100 seconds, because the end-to-end panel test runs the fake `claude` for every role session.

1. **The Committer works on real rooms.** For 40 generated `r2` deals, quoting the line that holds each value and range evidence, as an Investigator would, commits the answer-key amount every time. The difference and product formulas were covered too (`test_every_real_value_and_range_can_be_committed_from_its_documents`).
2. **A no-Claude dry run on `data/cal-r2`'s 30 deals.** Scripted roles stood in for the LLMs:
   - an honest but naive Deal Lead: chance 0.3 on every issue, dropping to 0.1 once one is read without being settled
   - Investigators that report exactly what the documents they open say
   - a Challenger that never objects

   This measures what the machinery can reach, not how good the LLMs are.

   | System | Regret ÷ ask | Correct | Wrong on flips | Pages | Sessions |
   |---|---|---|---|---|---|
   | S1b (measured, calibration round 2) | 0.0195 | 0.733 | 6/17 | 20.3 | 1 |
   | `s4_2` (the Deal Lead's order) | 0.0257 | 0.733 | 6/17 | 21.9 | 9.1 |
   | `s4` (router + sweep) | **0.0098** | 0.833 | 4/17 | 22.5 | 7.9 |

   The router carries the gain in this setting. The Committer refused no honest report.
3. **Track A's veto stops S4 before it reads anything.** At 0.0025 × asking price per page, typical scores (about $0.15M per page on a $200M deal) are below the veto. Hence Decision 4.
4. **Two bugs found and fixed during pre-verification:**
   - A pair "check" used to overwrite the Challenger's own objection on the same issue. Objections are now a list per issue.
   - The router priced an issue at its first suggested document even when that one was already read. It now uses the first *unread* one.
5. **Session count.** S4 runs 8–10 sessions per deal in the dry run. Lead turns are small (no documents), but each session carries `claude -p`'s fixed overhead. Measure the real tokens in the Task 6 smoke run before sizing any larger run.

## Post-review changes (after execution)

- **Task 2 ruling:** a committed value's floor stands against an objection; the objection only widens the top until it is checked.
- **Task 4 ruling:** the tool server validates every closing-call field the panel reads (Deal Lead and Challenger replies), so a malformed reply is a tool error, not a crash.
- **F1:** a later commit that disagrees with a committed value widens it to a range covering both and keeps every quote, instead of overwriting it.
- **F2:** computed values: exactly two inputs with their order spelled out; a negative difference is refused (report 0 with a quote); product finds the percent input from the quotes in either order, and is refused without one.
- **F3:** the Deal Lead's list is the whole plan: an open issue it leaves out is dropped (chance 0).
- **F4:** S4's timed-out turns are carried in pilot rows and summed per system in the summary.
- **F5:** S3's N is S4's tokens over S1b's on the deals both answered with usage (paired), at least 1.
- **M1:** the Lead prompt says code may reorder the reading and override stop; the `Config.router` comment describes the real behaviour.
- **M2:** the isolation test also checks `panel` and `panel_prompts` for answer-key words.
- **R1:** a re-plan no longer drops an open issue with a pending Challenger objection, so the router still gives it its extra look.
- **R2:** while an objection is pending, a re-plan can't lower the issue's chance or size below the objection's; after the look the Lead sets it freely.
- **R3:** product picks the input that matches a quoted percent's fraction before one that matches a printed percent figure, so an amount that is also a printed percent is not mistaken for it.
- **S1 (smoke run):** an objection no longer changes the Deal Lead's belief. It prices its issue only while pending (the higher of the Lead's and the objection's chance and size), so an unchecked objection changes nothing in the final call; this replaces R1's and R2's guards in `plan()`. On dev-000, two unchecked objections alone had forced NO-GO.
- **S2 (smoke run):** the residual sweep reads only documents on the diligence map (untouched domains first, then the shortest), not filler like it_policy or environmental.

```python
"""The Committer (main spec §3; reframe design §5): code accepts a finding only when its evidence checks out.
LLMs read and judge; this file checks quotes and does the arithmetic. It sees only the text of documents the
session has read, never an answer key.

A finding is one issue type's result:
- value: an amount, quoted (a number in a verbatim quote) or computed (code applies op to two quoted numbers)
- range: low and high, each 0 or a number in a quote (an unresolvable amount, or documents that disagree)
- not_found: the documents read that don't settle it
- open: a belief with no evidence yet (chance and range)
"""
import math
import re

from acqlab.generator.traps import TRAPS

OPS = ("none", "difference", "product", "divide")
MIN_QUOTE = 12  # characters, after normalising: shorter quotes prove nothing
TOL = 0.051  # $M: amounts print with one decimal
_NUM = re.compile(r"(\d[\d,]*(?:\.\d+)?)\s*(%?)")
_WORDS = {w: float(i) for i, w in enumerate(
    "zero one two three four five six seven eight nine ten eleven twelve".split())}


def norm(text: str) -> str:
    """Lower case, one kind of dash, markdown table and emphasis marks dropped, whitespace collapsed."""
    text = text.lower().replace("–", "-").replace("—", "-").replace("’", "'")
    return " ".join(re.sub(r"[|*#`>]", " ", text).split())


def numbers(quote: str) -> list[float]:
    """Every number in a quote. A percentage also counts as its fraction (25.0% gives 25.0 and 0.25); number words
    up to twelve count too ("five-year plan")."""
    out = []
    for digits, percent in _NUM.findall(quote):
        x = float(digits.replace(",", ""))
        out += [x, x / 100] if percent else [x]
    out += [_WORDS[w] for w in re.findall(r"[a-z]+", quote.lower()) if w in _WORDS]
    return out


def _in(x: float, nums: list[float]) -> bool:
    return any(abs(x - n) <= TOL or math.isclose(x, n, rel_tol=1e-6) for n in nums)


def _num(v) -> float | None:
    return float(v) if isinstance(v, (int, float)) and not isinstance(v, bool) and math.isfinite(v) else None


def check(finding: dict, texts: dict[str, str]) -> tuple[dict | None, list[str]]:
    """(commit, errors). `texts` maps each document the session may cite to its text. A commit is
    {"type", "kind": quoted|computed|range|not_found|open, "low", "high", "chance", "quotes", "docs"}."""
    t, status = finding.get("type"), finding.get("status")
    if t not in TRAPS:
        return None, [f"type must be one of {', '.join(TRAPS)}"]
    errors: list[str] = []
    quotes = finding.get("quotes") or []
    nums: list[float] = []
    for q in quotes:
        doc, text = (q.get("doc_id"), q.get("text")) if isinstance(q, dict) else (None, None)
        if doc not in texts:
            errors.append(f"{t}: quote from {doc!r}, which you have not read")
        elif not isinstance(text, str) or len(norm(text)) < MIN_QUOTE or norm(text) not in norm(texts[doc]):
            errors.append(f"{t}: the quote {text!r} is not in {doc} word for word (copy at least {MIN_QUOTE} "
                          "characters exactly)")
        else:
            nums += numbers(text)
    base = {"type": t, "chance": 1.0, "quotes": quotes, "docs": sorted({q["doc_id"] for q in quotes
                                                                          if isinstance(q, dict) and "doc_id" in q})}
    if status == "value":
        op = finding.get("op", "none")
        if op not in OPS:
            return None, errors + [f"{t}: op must be one of {', '.join(OPS)}"]
        if op == "none":
            v = _num(finding.get("value"))
            if not quotes:
                errors.append(f"{t}: a value needs a quote")
            if v is None or v < 0:
                errors.append(f"{t}: value must be a number >= 0")
            elif v > 0 and not _in(v, nums):
                errors.append(f"{t}: {v} does not appear in your quotes")
            return (None, errors) if errors else ({**base, "kind": "quoted", "low": v, "high": v}, [])
        inputs = finding.get("inputs")
        a, b = (_num(inputs[0]), _num(inputs[1])) if isinstance(inputs, list) and len(inputs) == 2 else (None, None)
        if not quotes:
            errors.append(f"{t}: a computed value needs quotes holding both inputs")
        if a is None or b is None:
            return None, errors + [f"{t}: inputs must be two numbers"]
        for x in (a, b):
            if not _in(x, nums):
                errors.append(f"{t}: input {x} does not appear in your quotes")
        if op == "divide" and b <= 0:
            errors.append(f"{t}: cannot divide by {b}")
        if errors:
            return None, errors
        v = {"difference": max(0.0, a - b), "product": a * (b / 100 if b > 1 else b), "divide": a / b}[op]
        return {**base, "kind": "computed", "low": v, "high": v}, []
    if status == "range":
        lo, hi = _num(finding.get("low")), _num(finding.get("high"))
        if lo is None or hi is None or not 0 <= lo <= hi:
            return None, errors + [f"{t}: need 0 <= low <= high"]
        if not quotes:
            errors.append(f"{t}: a range needs a quote")
        errors += [f"{t}: {x} does not appear in your quotes" for x in (lo, hi) if x > 0 and not _in(x, nums)]
        return (None, errors) if errors else ({**base, "kind": "range", "low": lo, "high": hi}, [])
    if status == "not_found":
        docs = finding.get("docs")
        if not isinstance(docs, list) or not docs:
            return None, errors + [f"{t}: list the documents you read that don't settle it"]
        errors += [f"{t}: you have not read {d!r}" for d in docs if d not in texts]
        return (None, errors) if errors else ({**base, "kind": "not_found", "low": None, "high": None,
                                               "docs": [str(d) for d in docs]}, [])
    if status == "open":
        c, lo, hi = _num(finding.get("chance")), _num(finding.get("low")), _num(finding.get("high"))
        if c is None or lo is None or hi is None or not (0 <= c <= 1 and 0 <= lo <= hi):
            return None, errors + [f"{t}: need 0 <= chance <= 1 and 0 <= low <= high"]
        return (None, errors) if errors else ({**base, "kind": "open", "chance": c, "low": lo, "high": hi}, [])
    return None, [f"{t}: status must be value, range, not_found or open"]
```

```python
"""The Deal Record (main spec §3, the blackboard): what S4 believes about each issue type, and the evidence behind it.
Code holds it; LLMs only propose. The engine prices it: the decision, each issue's flip amount, the pairs that
flip together, and router 6's ranking (reframe design §5).

It reads the room's engine.json and index.json only, never an answer key."""
import json
from dataclasses import dataclass, field
from pathlib import Path
from typing import NamedTuple

import numpy as np

from acqlab.agents.knowledge import DILIGENCE_MAP, typical_high
from acqlab.engine import Deal, is_go
from acqlab.generator.sample import Teaser
from acqlab.generator.traps import TRAPS, params_for
from acqlab.routers.beliefs import HAIRCUT_CAP, Issue, draw, walk_aways
from acqlab.routers.routers import decide, score_regret

N_WORLDS = 400
PAIR_TOP = 3  # the pair screen looks at the top open issues by chance x size
FLIP_STEPS = 30  # bisection steps for a flip amount


class Face(NamedTuple):
    """The deal at face value, from visible numbers only. Stands in for BaseDeal in params_for and walk_aways, which
    read only .teaser and .deal."""
    teaser: Teaser
    deal: Deal


def load_face(room: Path) -> Face:
    engine = json.loads((room / "engine.json").read_text())
    return Face(Teaser(**engine["teaser"]), Deal(**engine["deal"]))


def next_doc(trap: str, pages: dict[str, float], read: set[str]) -> str | None:
    """The first unread document on the diligence map for this issue type, or None once all are read."""
    for kind in DILIGENCE_MAP[trap]:
        for d in sorted(x for x in pages if x == kind or x.startswith(kind + "_")):
            if d not in read:
                return d
    return None


@dataclass
class Entry:
    """One issue type. `known` is a committed (low, high); otherwise the Deal Lead's belief (chance, low, high)
    stands, priced over at least the usual size range."""
    trap: str
    name: str = ""
    proposed: bool = False
    chance: float = 0.0
    low: float = 0.0
    high: float = 0.0
    docs: list[str] = field(default_factory=list)
    known: tuple[float, float] | None = None
    kind: str | None = None  # quoted | computed | range
    quotes: list[dict] = field(default_factory=list)
    searched: list[str] = field(default_factory=list)
    tries: int = 0
    objections: list[dict] = field(default_factory=list)  # unanswered Challenger objections

    @property
    def open(self) -> bool:
        return self.proposed and self.known is None


class Record:
    def __init__(self, face: Face):
        self.face = face
        self.entries = {t: Entry(t) for t in TRAPS}
        self.priority: list[str] = []  # the Deal Lead's order, most important first

    def plan(self, issues: list[dict]) -> None:
        """A Deal Lead proposal. Committed values stand; beliefs about the rest are replaced."""
        self.priority = [i["type"] for i in issues]
        for i in issues:
            e = self.entries[i["type"]]
            e.proposed, e.name, e.docs = True, i.get("name", ""), list(i.get("docs", []))
            if e.known is None:
                e.chance, e.low, e.high = float(i["chance"]), float(i["low"]), float(i["high"])

    def apply(self, commits: list[dict]) -> bool:
        """Committed findings; True if any narrowed what is known."""
        narrowed = False
        for c in commits:
            e = self.entries[c["type"]]
            e.proposed = True
            if c["kind"] in ("quoted", "computed", "range"):
                narrowed |= e.known != (c["low"], c["high"])
                e.known, e.kind, e.quotes = (c["low"], c["high"]), c["kind"], c["quotes"]
            elif c["kind"] == "not_found":
                e.searched = sorted(set(e.searched) | set(c["docs"]))
            elif e.known is None:  # open: a belief without evidence
                e.chance, e.low, e.high = c["chance"], c["low"], c["high"]
        return narrowed

    def challenge(self, objections: list[dict]) -> None:
        """Each objection reopens its issue for one more investigation. For an open issue it also widens the belief:
        the higher chance and the larger size stand."""
        for o in objections:
            e = self.entries[o["type"]]
            e.proposed = True
            e.objections.append(o)
            e.docs = list(dict.fromkeys(list(o.get("docs", [])) + e.docs))
            if e.known is None:
                e.chance, e.high = max(e.chance, o["chance"]), max(e.high, o["high"])

    def issue(self, t: str) -> Issue:
        e = self.entries[t]
        if e.known is not None and e.objections:  # in doubt until checked: the committed floor stands, the top widens
            return Issue(known=(e.known[0], max([o["high"] for o in e.objections] + [e.known[1]])))
        if e.known is not None:
            return Issue(known=e.known)
        if not e.proposed:
            return Issue(proposed=False)
        return Issue(p_real=e.chance, hi=max(e.high, typical_high(t, self.face.teaser)))

    def worlds(self) -> tuple[np.ndarray, np.ndarray]:
        values = draw({t: self.issue(t) for t in TRAPS}, N_WORLDS, np.random.default_rng(0))
        return values, walk_aways(self.face, values)

    def decide(self) -> tuple[bool, float]:
        """The engine's call at the committed beliefs (main spec §3: code decides): go if its expected regret is no
        higher than passing, and the median walk-away."""
        return decide(self.worlds()[1], self.face.deal.asking_price)

    def point(self) -> dict[str, float]:
        """Committed values at their midpoints; open issues at 0 (face value)."""
        return {t: (e.known[0] + e.known[1]) / 2 if e.known else 0.0 for t, e in self.entries.items()}

    def _go(self, amounts: dict[str, float]) -> bool:
        a = dict(amounts)
        a["concentration"] = min(a.get("concentration", 0.0), HAIRCUT_CAP * self.face.teaser.revenue_ltm)
        return is_go(self.face.deal, params_for(a, self.face))

    def size_limit(self, t: str) -> float:
        return max(self.entries[t].high, typical_high(t, self.face.teaser))

    def flip_amount(self, t: str) -> float | None:
        """$M of issue t at which the decision flips, the others at their point values; None if no size up to twice
        the usual range flips it."""
        base = self.point()
        lo, hi = 0.0, 2 * self.size_limit(t)
        go_lo = self._go(base | {t: lo})
        if self._go(base | {t: hi}) == go_lo:
            return None
        for _ in range(FLIP_STEPS):
            mid = (lo + hi) / 2
            lo, hi = (mid, hi) if self._go(base | {t: mid}) == go_lo else (lo, mid)
        return hi

    def flagged_pairs(self) -> list[tuple[str, str]]:
        """Pairs of the top open issues that flip the decision together at the top of their size ranges, when neither
        does alone (reframe design §5: "these two together flip it")."""
        open_ = sorted((t for t, e in self.entries.items() if e.open and e.chance > 0),
                       key=lambda t: -self.entries[t].chance * self.size_limit(t))[:PAIR_TOP]
        base = self.point()
        now = self._go(base)
        alone = {t: self._go(base | {t: self.size_limit(t)}) != now for t in open_}
        return [(a, b) for i, a in enumerate(open_) for b in open_[i + 1:]
                if not alone[a] and not alone[b]
                and self._go(base | {a: self.size_limit(a), b: self.size_limit(b)}) != now]

    def rank(self, candidates: list[str], costs: dict[str, float]) -> dict[str, float]:
        """Router 6: expected $M of decision regret removed per page, for each candidate issue."""
        values, w = self.worlds()
        return score_regret(values, w, self.face.deal.asking_price, costs, candidates)

    def view(self, reasons: bool = True) -> str:
        """The record as text, for the Deal Lead (and, without the Lead's issue names, the Challenger)."""
        go, wa = self.decide()
        lines = [f"Engine's current call at these beliefs: {'GO' if go else 'NO-GO'} (median walk-away "
                 f"${wa:,.1f}M vs asking ${self.face.deal.asking_price:,.1f}M)."]
        for t, e in self.entries.items():
            head = f"- {t}" + (f" ({e.name})" if reasons and e.name else "")
            if e.known is not None:
                lo, hi = e.known
                amount = f"${lo:,.1f}M" if lo == hi else f"${lo:,.1f}–${hi:,.1f}M"
                src = "; ".join(f'{q["doc_id"]}: "{q["text"]}"' for q in e.quotes)
                lines.append(f"{head}: committed {amount} ({e.kind}) from {src}")
            elif e.proposed:
                lines.append(f"{head}: open, chance {e.chance:.2f}, size ${e.low:,.1f}–${e.high:,.1f}M"
                             + (f"; read without settling it: {', '.join(e.searched)}" if e.searched else ""))
            else:
                lines.append(f"{head}: not proposed (treated as no problem)")
        return "\n".join(lines)
```

```python
def _room(data, deal="dev-000"):
    return data / "deals" / deal / "room"


def _budget(data, deal="dev-000") -> float:
    return AnswerKey.model_validate_json((data / "truth" / f"{deal}.json").read_text()).budget


def _rows(trace) -> list[dict]:
    return [json.loads(x) for x in trace.read_text().splitlines()]


def _issue(t, chance=0.5, high=2.0, docs=()):
    return {"type": t, "name": t, "chance": chance, "low": 0, "high": high, "docs": list(docs)}


def scripted(**roles):
    """A stand-in for run_session: each turn runs a real tool Session in-process and hands it to the role's script
    (session, prompt). Records (role, prompt, budget) for every turn."""
    turns = []

    def session(room, budget, trace, prompt, system, tools, args):
        a = dict(zip(args[::2], args[1::2]))
        assert tools == ROLES[a["--role"]]
        s = Session(room, budget, trace, False, a["--role"], tuple(d for d in a["--paid"].split(",") if d),
                    tuple(map(tuple, json.loads(a.get("--pairs", "[]")))))
        turns.append((a["--role"], prompt, budget))
        roles[a["--role"]](s, prompt)
        return {"usage": {"output_tokens": 7}, "total_cost_usd": 0.01, "num_turns": 2, "duration_ms": 5,
                "modelUsage": {"claude-opus-5-5": {}}, "env_keys": ["HOME"]}

    session.turns = turns
    return session


def lead_says(*plans):
    """The Deal Lead proposes each plan in turn (the last one repeats); a plan is (issues, stop)."""
    plans = list(plans)

    def lead(s, prompt):
        issues, stop = plans.pop(0) if len(plans) > 1 else plans[0]
        s.call("propose", {"issues": issues, "stop": stop, "reason": "r"})
    return lead


def finds_nothing(s, prompt):
    """An Investigator that reads the first suggested document it can afford and settles nothing."""
    looked = re.search(r"Look first at: ([^.]*)\.", prompt)
    for doc in (looked.group(1).split(", ") if looked else []):
        if not s.call("open_document", {"doc_id": doc})["isError"]:
            s.call("report", {"findings": [{"type": "addback", "status": "not_found", "docs": [doc]}]})
            return
    s.call("report", {"findings": []})


def no_objections(s, prompt):
    s.call("challenge", {"objections": [], "pairs": [{"a": a, "b": b, "answer": "ruled_out", "reason": "r"}
                                                     for a, b in s.pairs]})


def _briefed(turns) -> list[str]:
    return [re.search(r"Find out: (\w+)", p).group(1) for r, p, _ in turns if r == "investigator" and "Find out" in p]


@pytest.mark.parametrize("stage", list(STAGES))
def test_every_build_step_runs_end_to_end_and_the_engine_decides(data, tmp_path, fake_claude, monkeypatch, stage):
    monkeypatch.setenv("FAKE_CLAUDE", "ok")
    trace, budget = tmp_path / "t.jsonl", _budget(data)

    assert ("propose" in tools) == STAGES[stage].lead and ("challenge" in tools) == STAGES[stage].challenger
    if stage == "s4_1":
        assert cli["sessions"] == 1

def test_the_router_ranks_by_regret_per_page_and_stops_below_the_veto(data, tmp_path, monkeypatch):
    plan = [_issue("nwc", 0.3), _issue("debt_like", 0.6)]
    s = scripted(lead=lead_says((plan, True)), investigator=finds_nothing, challenger=no_objections)
    p = Panel(_room(data), 40, tmp_path / "a.jsonl", Config(challenger=False, sweep=False), s)
    p.record.plan(plan)
    costs = {t: p.first_cost(t) for t in ("nwc", "debt_like")}
    scores = p.record.rank(["nwc", "debt_like"], costs)
    p.run()
    assert _briefed(s.turns)[0] == max(scores, key=scores.get)  # the Lead's stop doesn't end a router run
    monkeypatch.setattr(panel, "VETO", 1.0)  # nothing removes a whole asking price of regret per page
    s2 = scripted(lead=lead_says((plan, False)), investigator=finds_nothing)
    Panel(_room(data), 40, tmp_path / "b.jsonl", Config(challenger=False, sweep=False), s2).run()
    assert _briefed(s2.turns) == []

def test_an_objection_buys_one_more_look_and_a_checked_pair_becomes_two(data, tmp_path):
    plan = [_issue("debt_like", 0.5, docs=["legal"]), _issue("nwc", 0.5, docs=["qoe"])]
    rounds = [
        {"objections": [{"type": "debt_like", "kind": "elsewhere", "chance": 0.4, "low": 0, "high": 9,
                         "docs": ["audited"], "reason": "the notes list commitments"}],
         "pairs": [{"a": "debt_like", "b": "nwc", "answer": "check", "reason": "together"}]},
        {"objections": [], "pairs": []}]

    def challenger(sess, prompt):
        r = rounds.pop(0)
        sess.call("challenge", r | {"pairs": r["pairs"] or [{"a": a, "b": b, "answer": "ruled_out", "reason": "r"}
                                                             for a, b in sess.pairs]})

    s = scripted(lead=lead_says((plan, False)), investigator=finds_nothing, challenger=challenger)
    Panel(_room(data), 60, tmp_path / "t.jsonl", STAGES["s4_3"], s).run()
    assert _briefed(s.turns) == ["debt_like", "nwc", "debt_like", "nwc"]  # each once, then once more
    second = [p for r, p, _ in s.turns if r == "investigator"][2]
    assert "The Challenger objects (elsewhere): the notes list commitments" in second
    assert "Look first at: audited" in second
    assert [r for r, _, _ in s.turns].count("challenger") == 2
```

```python
_JOB = """A private-equity sponsor is deciding whether to buy a company at its asking price in a leveraged buyout. \
The data room may reveal problems that lower what the company is worth: add-backs that are not really one-time \
(addback), debt-like items payable at closing (debt_like), revenue that will be lost from a customer \

LEAD = f"""{_JOB}

def docs_table(docs: list[dict], read: set[str]) -> str:
    return "\n".join(f"- {d['id']}: {d['title']} ({d['domain']}, {d['pages']} pages)"
                     + (" [already read: free]" if d["id"] in read else "") for d in docs)


def lead_prompt(teaser: str, docs: list[dict], record: Record, read: set[str], left: float) -> str:
    return (f"{teaser}\n\nDocuments:\n{docs_table(docs, read)}\n\nReading budget left: {left:g} units.\n\n"
            f"Deal record:\n{record.view()}\n\nCall propose with your issue list.")


def brief(teaser: str, docs: list[dict], record: Record, trap: str, where: list[str], read: set[str],
          budget: float) -> str:
    """The intent brief (main spec §3): the issue, the current range, the engine's flip amount, where to look, and a
    sub-budget."""
    e = record.entries[trap]
    flip = record.flip_amount(trap)
    lines = [f"Find out: {trap}" + (f" ({e.name})" if e.name else "") + ".",
             f"Current belief: chance {e.chance:.2f}, size ${e.low:,.1f}–${e.high:,.1f}M." if e.known is None else
             f"Committed so far: ${e.known[0]:,.1f}–${e.known[1]:,.1f}M ({e.kind}).",
             f"The engine's call flips if this issue is at least ${flip:,.1f}M, with everything else as recorded."
             if flip is not None else
             f"No size up to ${2 * record.size_limit(trap):,.1f}M flips the call alone; it can still matter with "
             "other issues, so report what the documents say."]
    lines += [f"The Challenger objects ({o['kind']}): {o['reason']}" for o in e.objections]
    if e.searched:
        lines.append(f"Already read without settling it: {', '.join(e.searched)}.")
    lines.append(f"Look first at: {', '.join(where)}." if where else "Choose where to look.")
    return (f"{teaser}\n\nDocuments:\n{docs_table(docs, read)}\n\nBrief:\n" + "\n".join(lines)
            + f"\n\nYour reading budget: {budget:g} units. Report a finding for {trap}; add any other issue type "
            "the documents you read settle.")


def reader_prompt(teaser: str, docs: list[dict], budget: float) -> str:
    """Build step 1 (reframe design §5): one Investigator covers every issue type with the whole budget."""
    return (f"{teaser}\n\nDocuments:\n{docs_table(docs, set())}\n\nBrief: find out all five issue types. Report a "
            f"finding for each one you can.\n\nYour reading budget: {budget:g} units.")


def sweep_prompt(teaser: str, docs: list[dict], sweep: list[str], read: set[str], budget: float) -> str:
    """The residual sweep (main spec §3): undirected reads of documents nobody has opened."""
    return (f"{teaser}\n\nDocuments:\n{docs_table(docs, read)}\n\nBrief: read {', '.join(sweep)}, which the panel "
            "has not read, and report every issue type they settle, including ones nobody proposed.\n\nYour "
            f"reading budget: {budget:g} units.")


def challenger_prompt(teaser: str, docs: list[dict], record: Record, pairs: list[tuple[str, str]],
                      read: set[str], left: float) -> str:
    flagged = "\n".join(f"- {a} + {b}: each is too small to flip the call alone at the top of its range, but "
                        "together they flip it." for a, b in pairs) or "- none"
    return (f"{teaser}\n\nDocuments:\n{docs_table(docs, read)}\n\nReading budget left: {left:g} units.\n\n"
            f"Deal record:\n{record.view(reasons=False)}\n\nFlagged pairs:\n{flagged}\n\nCall challenge.")
```

```python
"""S4, the multi-agent panel (main spec §3; reframe design §5). Code holds the Deal Record and runs the loop; each
role turn is one sandboxed `claude -p` session on the tool server, and the role's closing tool call (propose,
report, challenge) is read back from the trace. The engine makes the go/no-go call.

The loop: the Deal Lead proposes issues; Investigators check them one at a time with intent briefs, their findings
going through the Committer; the Lead re-plans after each; the Challenger objects and the pair screen flags issues
that flip the call together; objections are investigated; a residual sweep reads what nobody opened. Build steps
(reframe design §5) are configs: STAGES."""
import json
import math
from collections.abc import Callable
from functools import partial
from pathlib import Path
from typing import NamedTuple

from acqlab.agents import panel_prompts as prompts
from acqlab.agents.record import Record, load_face, next_doc
from acqlab.agents.server import ROLES
from acqlab.agents.solver import RunTimeout, run_session
from acqlab.generator.traps import TRAPS

SWEEP_SHARE = 0.10  # budget held back for the residual sweep (main spec §3)
SUB_SHARE = 0.5  # an Investigator's budget: its first document plus 2 units, and at least half the deal budget
MAX_TRIES = 2  # investigations per issue: once, and once more after an objection
CHALLENGE_ROUNDS = 2
VETO = 0.0  # the router stops once no issue removes more than this share of the asking price per page. Unspent
# budget earns nothing under the regret score, so a page costs nothing: stop only when nothing has decision value
# left. ponytail: Track A's regret+veto used 0.0025, which stops before any reading on ordinary deals.
SYSTEM = {"lead": prompts.LEAD, "investigator": prompts.INVESTIGATOR, "challenger": prompts.CHALLENGER}
USAGE = ("input_tokens", "output_tokens", "cache_read_input_tokens", "cache_creation_input_tokens")


class Config(NamedTuple):
    lead: bool = True  # False: build step 1, one Investigator reads for every issue type
    challenger: bool = True
    router: bool = True  # False: issues in the Deal Lead's order, stopping when the Lead says stop
    sweep: bool = True


STAGES = {"s4_1": Config(False, False, False, False), "s4_2": Config(True, False, False, False),
          "s4_3": Config(True, True, False, False), "s4": Config()}


class Panel:
    def __init__(self, room: Path, budget: float, trace: Path, cfg: Config, session: Callable):
        self.room, self.budget, self.trace, self.cfg, self.session = room, budget, trace, cfg, session
        index = json.loads((room / "index.json").read_text())
        self.teaser, self.docs = index["teaser"], index["documents"]
        self.pages = {d["id"]: d["pages"] for d in self.docs}
        self.record = Record(load_face(room))
        self.reserve = SWEEP_SHARE * budget if cfg.sweep else 0.0
        self.cli = {"usage": dict.fromkeys(USAGE, 0), "total_cost_usd": 0.0, "num_turns": 0, "duration_ms": 0,
                    "modelUsage": {}, "sessions": 0, "timeouts": 0, "env_keys": None}

    def rows(self) -> list[dict]:
        return [json.loads(x) for x in self.trace.read_text().splitlines()] if self.trace.exists() else []

    def spent(self) -> float:
        return sum(r["cost"] for r in self.rows())

    def read(self) -> set[str]:
        return {r["args"]["doc_id"] for r in self.rows() if r["tool"] == "open_document" and not r["refused"]}

    def avail(self) -> float:
        """Budget for directed reading: what is left, less the sweep's reserve."""
        return self.budget - self.spent() - self.reserve

    def turn(self, role: str, prompt: str, budget: float, extra: list[str] | None = None) -> dict | None:
        """One role session; its last accepted closing call (trace row), or None if it never made one."""
        n = len(self.rows())
        args = ["--role", role, "--paid", ",".join(sorted(self.read()))] + (extra or [])
        try:
            out = self.session(self.room, max(0.0, budget), self.trace, prompt, SYSTEM[role], ROLES[role], args)
        except RunTimeout:
            self.cli["timeouts"] += 1
            out = None
        self.cli["sessions"] += 1
        if out:
            for k in USAGE:
                self.cli["usage"][k] += int(out.get("usage", {}).get(k, 0))
            for k in ("total_cost_usd", "num_turns", "duration_ms"):
                self.cli[k] += out.get(k) or 0
            self.cli["modelUsage"] |= out.get("modelUsage", {})
            self.cli["env_keys"] = out.get("env_keys")
        done = [r for r in self.rows()[n:] if r["tool"] in ("propose", "report", "challenge") and not r["refused"]]
        return done[-1] if done else None

    def lead(self) -> bool:
        """The Deal Lead's (re-)plan; True if it says stop (or made no plan)."""
        row = self.turn("lead", prompts.lead_prompt(self.teaser, self.docs, self.record, self.read(),
                                                    self.budget - self.spent()), 0)
        if row is None:
            return True
        self.record.plan(row["args"]["issues"])
        return row["args"]["stop"]

    def candidates(self) -> list[str]:
        """Issues due an investigation: open ones not yet tried, and any with an unanswered objection."""
        return [t for t, e in self.record.entries.items() if e.proposed and e.tries < MAX_TRIES and (
            e.objections or (e.known is None and e.chance > 0 and e.tries == 0))]

    def where(self, t: str) -> list[str]:
        e = self.record.entries[t]
        return [d for d in dict.fromkeys(e.docs + [next_doc(t, self.pages, self.read())]) if d in self.pages]

    def first_cost(self, t: str) -> float:
        """Pages of the first unread document to check for issue t (1 if all are read: a search)."""
        read = self.read()
        return float(next((self.pages[d] for d in self.where(t) if d not in read), 1))

    def pick(self) -> str | None:
        cands = self.candidates()
        if not cands:
            return None
        if not self.cfg.router:
            order = self.record.priority
            return min(cands, key=lambda t: (order.index(t) if t in order else len(order), TRAPS.index(t)))
        costs = {t: self.first_cost(t) for t in cands}
        scores = self.record.rank(cands, costs)
        best = max(cands, key=lambda t: (scores[t], -TRAPS.index(t)))
        return best if scores[best] > VETO * self.record.face.deal.asking_price else None

    def investigate(self, t: str) -> None:
        e = self.record.entries[t]
        where = self.where(t)
        sub = min(self.avail(), max(self.first_cost(t) + 2, math.ceil(SUB_SHARE * self.budget)))
        prompt = prompts.brief(self.teaser, self.docs, self.record, t, where, self.read(), sub)
        e.tries += 1
        e.objections = []  # answered by this investigation, whatever it finds
        if sub >= 1:
            row = self.turn("investigator", prompt, sub)
            self.record.apply(row["result"]["commits"] if row else [])

    def directed(self) -> None:
        while self.avail() >= 1 and (t := self.pick()) is not None:
            self.investigate(t)
            if self.lead() and not self.cfg.router:
                break

    def challenge(self) -> None:
        for _ in range(CHALLENGE_ROUNDS):
            pairs = self.record.flagged_pairs()
            row = self.turn("challenger", prompts.challenger_prompt(self.teaser, self.docs, self.record, pairs,
                                                                   self.read(), self.budget - self.spent()), 0,
                            ["--pairs", json.dumps(pairs)])
            if row is None:
                return
            objections = list(row["args"]["objections"])
            for p in row["args"]["pairs"]:
                if p["answer"] == "check":
                    for t, other in ((p["a"], p["b"]), (p["b"], p["a"])):
                        e = self.record.entries[t]
                        objections.append({"type": t, "kind": "pair", "chance": e.chance, "low": e.low,
                                           "high": e.high, "docs": [], "reason": f"with {other}, it could flip "
                                           "the call: " + p["reason"]})
            if not objections:
                return
            self.record.challenge(objections)
            self.directed()

    def sweep(self) -> None:
        """Undirected reads by coverage: documents in untouched domains first, then the shortest."""
        left, read = self.budget - self.spent(), self.read()
        touched = {d["domain"] for d in self.docs if d["id"] in read}
        picked: list[str] = []
        for d in sorted((d for d in self.docs if d["id"] not in read),
                        key=lambda d: (d["domain"] in touched, d["pages"], d["id"])):
            if sum(self.pages[p] for p in picked) + d["pages"] <= left:
                picked.append(d["id"])
        if picked:
            row = self.turn("investigator", prompts.sweep_prompt(self.teaser, self.docs, picked, read, left), left)
            self.record.apply(row["result"]["commits"] if row else [])

    def run(self) -> dict:
        if not self.cfg.lead:
            row = self.turn("investigator", prompts.reader_prompt(self.teaser, self.docs, self.budget), self.budget)
            self.record.apply(row["result"]["commits"] if row else [])
        else:
            self.lead()
            self.directed()
            if self.cfg.challenger:
                self.challenge()
            if self.cfg.sweep:
                self.sweep()
        for e in self.record.entries.values():  # an objection nobody could afford to check changes nothing
            e.objections = []
        go, wa = self.record.decide()
        with self.trace.open("a") as f:
            f.write(json.dumps({"i": 0, "tool": "submit", "args": {"go": go, "walk_away": wa, "reason": "engine"},
                                "cost": 0.0, "remaining": self.budget - self.spent(), "refused": False,
                                "error": None, "result": {"submitted": True}}) + "\n")
        return self.cli


def solve(room: Path, budget: float, trace: Path, cfg: Config, *, claude: str | None = None,
          session: Callable | None = None) -> dict:
    """One S4 run; returns the sessions' summed CLI usage in the single-agent solver's shape. Raises LLMUnavailable
    (usage limit, auth) so the pilot stops and can resume; a timed-out session is skipped."""
    return Panel(room.resolve(), budget, trace.resolve(), cfg, session or partial(run_session, claude=claude)).run()
```
